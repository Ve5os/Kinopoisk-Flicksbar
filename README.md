# Kinopoisk → Flicksbar

<img width="600" height="269" alt="изображение" src="https://github.com/user-attachments/assets/c420b5d4-7a33-47a2-a441-fceaacc10ee0" />


Пользовательский скрипт (userscript) для Tampermonkey, который добавляет на страницы Кинопоиска кнопку **«Смотреть на Flicksbar»** — рядом с кнопкой «Буду смотреть». По клику открывает ту же страницу фильма на [kinokino.red](https://kinokino.red) в новой вкладке, сохраняя путь и все параметры URL.

## Что делает

- Ищет на странице кнопку «Буду смотреть» (по тексту, а не по обфусцированным классам — это устойчиво к обновлениям Кинопоиска).
- Рядом справа клонирует её визуал: те же размеры, цвета, темы, hover-состояния, иконка play слева.
- По клику берёт текущий адрес, заменяет домен на `kinokino.red` и открывает результат в новой вкладке.

Пример:
https://www.kinopoisk.ru/film/1234567/?ysclid=abc
↓ клик
https://kinokino.red/film/1234567/?ysclid=abc


## Установка

### 1. Установить Tampermonkey

Расширение для браузера:

- [Chrome / Edge / Opera](https://www.tampermonkey.net/?ext=dhdg)
- [Firefox](https://www.tampermonkey.net/?ext=firefox)
- [Safari](https://www.tampermonkey.net/?ext=safari)

### 2. Установить скрипт

**Способ А — вручную:**

1. Откройте панель Tampermonkey → **«Создать новый скрипт»**.
2. Удалите шаблон и вставьте содержимое файла `Kinopoisk → Flicksbar-1.3.user.js`
3. **Ctrl+S** (Cmd+S на Mac) — сохранить.
4. Готово.

**Способ Б — из репозитория (raw):**

1. Откройте файл `Kinopoisk → Flicksbar-1.3.user.js` в этом репозитории.
2. Нажмите **Raw**.
3. Tampermonkey предложит установить скрипт — согласитесь.

### 3. Проверка

Зайдите на любую страницу фильма/сериала на [kinopoisk.ru](https://www.kinopoisk.ru). Рядом с «Буду смотреть» должна появиться кнопка **«Смотреть на Flicksbar»** с иконкой ▶.

## Использование

Просто нажмите на кнопку **«Смотреть на Flicksbar»** — откроется соответствующая страница на kinokino.red в новой вкладке. Ничего настраивать не нужно.

## Настройка

Скрипт можно немного подправить под себя. Откройте его в Tampermonkey и измените нужные константы в начале:

| Что | Где | Значение по умолчанию |
|-----|-----|------------------------|
| Надпись на кнопке | `const LABEL` | `'Смотреть на Flicksbar'` |
| Целевой домен | `url.hostname = ...` в обработчике клика | `'kinokino.red'` |
| Размер иконки play | `makePlayIcon(16)` | `16` (px) |
