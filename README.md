Userscript для Tampermonkey. Добавляет на страницы Кинопоиска кнопку **«Смотреть на Flicksbar»** — рядом с кнопками «Буду смотреть» и «Купить и смотреть». По клику открывает ту же страницу фильма на [kinokino.red](https://kinokino.red) в новой вкладке, сохраняя путь и все параметры URL.

## Что делает

- Ищет на странице кнопки **«Буду смотреть»** и **«Купить и смотреть»** по тексту (не по обфусцированным классам — устойчиво к обновлениям Кинопоиска).
- Рядом с каждой клонирует её визуал: те же размеры, цвета, темы, hover-состояния; слева — иконка ▶.
- По клику берёт текущий адрес, заменяет домен на `kinokino.red` и открывает результат в новой вкладке.

Пример:
https://www.kinopoisk.ru/film/1234567/?ysclid=abc
↓ клик
https://kinokino.red/film/1234567/?ysclid=abc

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (Chrome / Edge / Opera / Firefox / Safari).
2. Откройте панель Tampermonkey → **«Создать новый скрипт»**.
3. Удалите шаблон, вставьте содержимое файла `Kinopoisk → Flicksbar.user.js` и сохраните (**Ctrl+S** / **Cmd+S**).

Либо: откройте файл скрипта в репозитории, нажмите **Raw** — Tampermonkey предложит установку.

## Проверка

Зайдите на страницу фильма/сериала на [kinopoisk.ru](https://www.kinopoisk.ru). Рядом с «Буду смотреть» или «Купить и смотреть» должна появиться кнопка **«Смотреть на Flicksbar»** с иконкой ▶.

## Использование

Нажмите **«Смотреть на Flicksbar»** — откроется соответствующая страница на `kinokino.red` в новой вкладке. Настраивать ничего не нужно.

## Настройка

Откройте скрипт в Tampermonkey и измените константы в начале:

| Что | Где | По умолчанию |
|-----|-----|--------------|
| Тексты кнопок, рядом с которыми появляется клон | `const ORIGINAL_TEXTS` | `['Буду смотреть', 'Купить и смотреть']` |
| Надпись на кнопке | `const LABEL` | `'Смотреть на Flicksbar'` |
| Целевой домен | `url.hostname = ...` в обработчике клика | `'kinokino.red'` |
| Размер иконки play | `makePlayIcon(16)` | `16` (px) |

Примеры:

```js
// Добавить ещё одну кнопку-«оригинал»
const ORIGINAL_TEXTS = ['Буду смотреть', 'Купить и смотреть', 'Смотреть'];

// Сменить целевой домен
url.hostname = 'example.com';
